# MabiChecker

瑪奇 Mabinogi（台服）遊戲檔案完整性檢查 / 修復工具

放進遊戲目錄執行，依官方檔案清單逐一比對檔案大小與 MD5，找出缺少或損毀的檔案，並可只重新下載有問題的檔案，不必重裝整個遊戲。

> **非官方工具。** 本專案與 Nexon、Beanfun 無關，僅讀取官方 CDN 上公開的檔案清單與遊戲檔案，行為與官方啟動器下載檔案時相同。使用風險請自行承擔。

## 功能

- 從官方 CDN 取得最新的 `version.txt`，比對遊戲目錄下每個檔案的**大小**與 **MD5**
- 每個檔案都列出檢查結果，結束後輸出 Summary 與異常檔案清單
- 只重新下載異常檔案，下載後先驗證 MD5，通過才取代原檔
- 支援下載續傳（伺服器不支援時自動從頭下載）、失敗自動重試
- 檢查與更新都在背景執行，視窗不會卡住，隨時可以按「停止」
- 單一 exe，不需要安裝，不需要額外執行環境

## 使用方式

1. 將 `MabiChecker.exe` 放進遊戲目錄（與 `Client.exe`、`version.dat` 同一層）。
2. 先確認遊戲與官方啟動器都已關閉。
3. 執行 `MabiChecker.exe`，按「**檢查**」。
4. 檢查完若有異常檔案，按「**更新**」修復。
5. 修復完成後，建議再按一次「檢查」確認。

> 完整檢查約需讀取 16 GB 的資料，時間取決於硬碟速度，SSD 約數分鐘，傳統硬碟可能超過十分鐘。

### 檢查結果標籤

| 標籤 | 意義 |
| --- | --- |
| `[OK]` | 大小與 MD5 皆正確 |
| `[缺少]` | 清單有、但本機找不到該檔案 |
| `[大小不符]` | 檔案大小與清單不同（此時不再計算 MD5） |
| `[MD5不符]` | 大小相同但內容不同 |
| `[無法讀取]` | 檔案無法開啟（權限或被鎖定），本工具無法修復 |
| `[略過]` | 清單中的佔位項目（大小 0、MD5 全 0），不算異常 |

遊戲目錄中有、但官方清單沒有的檔案（截圖、設定、自己的修改等）**一律不處理，也不會列出或刪除**。

## 運作原理

1. 讀取本機的 `version.dat`（4 bytes 的 little-endian 整數，即遊戲目前版本）。
2. 從 `http://tw.cdnpatch.mabinogi.beanfun.com/mabinogi/patch_live.txt` 取得線上版本與下載位置。
3. **版本必須一致才會進行比對。** 本機版本落後或不一致時，工具會停止並提示先用官方啟動器更新，避免把正常的舊版檔案誤判為損毀。
4. 下載檔案清單 `…/Mabinogi/live/version.txt`。每行格式為（以 Tab 分隔）：

   ```
   <相對路徑>  <檔案大小>  <MD5>  <最後修改的版本號>
   ```

5. 逐檔比對：先比大小，大小相同才計算 MD5（使用 Windows 內建的 CNG，不依賴第三方函式庫）。
6. 更新時，檔案由下列位置下載：

   ```
   http://tw.cdnpatch.mabinogi.beanfun.com/Mabinogi/live/Mabinogi/<相對路徑>
   ```

   檔案為單檔、未壓縮。

### 更新的安全機制

- 先下載到遊戲目錄下的 `_MabiChecker_tmp\`（與官方啟動器的 `patch\` 分開），MD5 驗證通過才取代原檔，下載中斷不會弄壞原本的檔案。
- 使用 HTTP Range 嘗試續傳，已下載的暫存內容在下次更新時會續用；若伺服器不支援，會自動改為從頭下載。
- 每個檔案最多重試 3 次。
- 遇到以下情況會拒絕更新：偵測到遊戲或啟動器正在執行、檢查後版本有變動、磁碟空間不足。
- 清單中不合法的路徑（絕對路徑、`..` 等）會被忽略，不會寫到遊戲目錄以外。
- **不會修改 `version.dat`**，版本號完全交給官方啟動器管理。

## 系統需求

- Windows 10 / 11（建議）
- 能連線到 `tw.cdnpatch.mabinogi.beanfun.com`（HTTP，80 埠）
- 對遊戲目錄有寫入權限。若遊戲安裝在需要權限的位置（例如 `Program Files`），更新時可能需要「以系統管理員身分執行」。

## 自行編譯

需要 Visual Studio 2022（或 Build Tools for Visual Studio 2022，勾選「使用 C++ 的桌面開發」）。

開啟「**x64 Native Tools Command Prompt for VS 2022**」，切換到原始碼資料夾後執行：

```bat
cl /nologo /EHsc /O2 /MT /W3 /utf-8 /DUNICODE /D_UNICODE MabiChecker.cpp /link /SUBSYSTEM:WINDOWS /OUT:MabiChecker.exe
```

或直接執行專案內的 `build.bat`。

- 純 Win32 API 實作，單一原始檔 `MabiChecker.cpp`。
- 使用 `/MT` 靜態連結 CRT，產出的 exe 可直接複製到其他電腦使用。
- 連結的系統函式庫：`winhttp`、`bcrypt`、`comctl32`、`comdlg32`、`user32`、`gdi32`（皆以 `#pragma comment(lib, ...)` 自動帶入）。

## 常見問題

**為什麼檢查一開始就停止，說版本不一致？**
官方檔案清單代表「線上最新版」。若你的遊戲還沒更新到最新版，比對結果會大量誤報。請先執行官方啟動器（`Mabinogi.exe`）更新，再使用本工具。

**「無法讀取」的檔案怎麼辦？**
通常是檔案被其他程式鎖定或權限不足。請關閉遊戲、啟動器與相關程式後重新檢查；仍無法解決時可嘗試以系統管理員身分執行。

**更新失敗，提示無法取代原檔？**
請確認遊戲與官方啟動器已完全關閉。已下載並驗證完成的內容會保留在 `_MabiChecker_tmp\`，再按一次「更新」會直接續用。

**更新後還需要用官方啟動器嗎？**
本工具只修復檔案內容，不處理版本號與啟動器本身。日常更新與啟動仍請使用官方啟動器。

**會傳送我的資料嗎？**
不會。工具只對官方 CDN 發出 HTTP GET 取得公開檔案，不上傳任何資料。

## 已知限制

- 目前只支援台服（Beanfun）的下載位置。伺服器位置會讀取 `patch_live.txt` 的 `ftp` 欄位；若該欄位是真正的 FTP 位置，則改用內建預設值。
- 官方 CDN 使用 HTTP 而非 HTTPS，因此下載後一律以 MD5 驗證內容。
- 下載續傳功能尚未經過實際測試；一般下載流程已驗證可正常運作。
- 若官方日後變更檔案清單格式或下載路徑，工具需要跟著調整。
